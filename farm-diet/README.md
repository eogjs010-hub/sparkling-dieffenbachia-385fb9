# 팜 다이어트 · Farm Diet

2024년 농산물소득조사 시설채소의 실제 조사표를 기반으로, 같은 작목의 순수익률 상위군과 사용자 비용을 300평 기준으로 비교합니다.

## 실행

Node.js 22 이상과 npm을 준비하고 이 폴더에서 실행합니다.

```bash
npm ci
npm run data:build
npm test
npm run build
npm run dev
```

개발 화면: http://127.0.0.1:3000/

프로덕션 빌드 후 `npm start`로 `out/`의 정적 사이트를 실행할 수 있습니다. `PORT` 환경변수로 포트를 변경할 수 있습니다. Next.js App Router, TypeScript, Tailwind CSS 4, Recharts를 사용합니다. Windows 환경의 호환성을 위해 webpack과 단일 빌드 작업 프로세스를 사용합니다.

## 원본 파일

로컬 제공 프로젝트의 `data/raw/`에는 원본 사본이 있습니다. 원본과 개인 식별정보는 Git·배포·소스 ZIP에 포함하지 않습니다. ZIP에서 재전처리하려면 다음 파일을 `data/raw/`에 넣으세요.

- `3. 농산물소득조사_시설채소_변수코드북_2015-2024.xlsx`
- `박대헌_시설채소_수박 외 10개 품목(2015-2024).xlsx`

다른 위치의 파일은 `FARM_DIET_RAW_DIR` 환경변수로 지정할 수 있습니다. 파일명이 다르면 `FARM_DIET_DATA_FILE`, `FARM_DIET_CODEBOOK_FILE`에 전체 경로를 지정합니다.

```powershell
$env:FARM_DIET_RAW_DIR='C:/Users/xhslt/OneDrive/바탕 화면/프로젝트 파일'
npm run data:build
```

결과: `src/data/benchmark-2024.json`. 2024년 시트만 읽습니다. 1행은 변수명, 2행은 단위이며 3행부터 조사표입니다. 코드북 `시설채소_2023-2024`의 418개 정의를 헤더 순서와 대조합니다. 숫자·상위 비용·회계 관계를 검산하고, 원본 SHA-256과 보류 사유를 기록합니다. 브라우저에는 집계 JSON만 포함되며 Excel 파서와 원본 파일은 포함되지 않습니다.

## 전처리 결과와 품질 정책

- 원본 조사표 1,130건 → 유효 조사표 1,127건, 13개 작목.
- 참외 914·926행: 같은 농가고유번호·작목에 다른 지역·비용이 있어 관련 두 행 모두 보류.
- 파프리카 1122행: 자가노동비·시간 누락으로 보류.
- 빈 비용은 무조건 0으로 확정하지 않습니다. 0 가정으로 소득·순수익·경영비·생산비 관계가 모두 5원 이내로 재현되는 경우에만 허용합니다. 이 검산은 무투입의 확정 증거가 아닙니다. 미응답 여부는 원자료 제공자 확인이 필요합니다.
- 숫자로 변환할 수 없는 값, 음수 비용, 핵심 지표 누락, 비양수 총수입, 기준면적 불일치는 제외합니다.
- 조사표 수와 고유 농가 수를 구분합니다. 한 농가가 여러 작목에 참여할 수 있습니다.
- 품질 정책을 변경하면 벤치마크와 관련 테스트를 다시 검증해야 합니다.

## 9대 비용의 실제 헤더 매핑

| 카테고리 | 계산식 |
|---|---|
| 종자·종묘비 | `종자/종묘비_비용` |
| 비료·영양제비 | `유기질비료_비용 + 무기질비료_비용` |
| 농약·방제비 | `농약비_비용` |
| 수도광열비 | `수도광열비_비용` |
| 시설·기타 재료비 | `기타재료비_비용` |
| 유지보수·감가상각비 | `대농기구상각비_비용 + 영농시설상각비_비용 + 수리유지비_합계` |
| 인건비 | `고용노동비_비용 + 위탁영농비_비용` |
| 임차료 | `임차료(농기계시설)_비용 + 토지임차료_비용` |
| 기회비용 | `자가노동비_비용 + 유동자본용역비_비용 + 고정자본용역비_비용 + 토지자본용역비_비용` |

집계와 세부 변수는 동시에 합산하지 않습니다. `임차료_비용` 및 세부 임차료도 추가하지 않습니다. `자가노동비(남)_비용`, `자가노동비(여)_비용`은 원/시간 단가로 총액이 아닙니다. 원본 반복 헤더를 객체로 일괄 변환하지 않고, 필요한 고유 헤더만 열 위치로 읽습니다.

`소농구비_비용`과 `기타비용_비용`은 9대 비용에 포함되지 않습니다. 두 비용 합계의 상위군 중앙값은 참고용으로 별도 집계합니다. 사용자 잔여액에서 이를 임의 추정해 차감하지 않습니다. 입력의 감가상각·종묘 자가생산 평가액·현물 노임·기회비용도 조사 개념에 맞춰야 합니다.

## 상위군과 지역 전환

순수익률 = `순수익_금액 / 총수입_금액 × 100`.

손실 농가도 유효 표본으로 유지합니다. 동일 작목 코호트를 내림차순 정렬하고 `ceil(n×0.1)`에 해당하는 경계까지 선정합니다. 경계 동점은 모두 포함하므로 선정 비율이 10%를 넘을 수 있습니다. JSON에 실제 비율을 기록합니다. 비용은 각 조사표의 카테고리 합을 먼저 계산한 뒤 같은 상위군에서 중앙값을 구합니다. 순수익률도 개인 비율의 중앙값이며, 순수익 중앙값을 매출 중앙값으로 나누지 않습니다.

지역 동일 작목은 유효 조사표 50건·상위군 5건 이상일 때만 사용합니다. 나머지는 전국 동일 작목으로 전환하며, 전국도 미달이면 비교를 보류합니다. 현재 지역 적용은 경상북도 시설참외 61건·상위군 7건뿐입니다. 시설참외 전국은 86건, 파프리카 전국은 55건, 수박 전국은 104건·상위군 11건입니다. 50건 기준은 참고 비교를 위한 운영 기준이며 통계적 신뢰도를 보장하지 않습니다.

## 표준화와 기간

원본 집계값은 모두 기준면적 300평으로 제공되므로 재환산하지 않습니다. 사용자 금액에만 `300 / 해당 작목 면적(평)`을 곱합니다. 여러 작목이 있는 농장은 해당 작목에 매출·비용을 배분합니다. 모든 세부 원자료가 300평 환산값인 것은 아닙니다. 실제 면적(㎡), 노임단가, 구입가 등은 별도 단위입니다.

300평 ≈ 991.74㎡이며 정확한 10a와 다릅니다. 재배기간·재포기간·1기작연수와 연간 금액의 관계는 추가 확인이 필요합니다. UI는 연간 입력을 받되 같은 조사대상 기간으로 맞추도록 안내합니다. 과거 연도를 단순 결합하지 않습니다.

## 페이지와 사용자 정보

- `/`: 간편·정밀 모드 선택
- `/diagnose/simple/`: 지역·작목·면적·매출·두 지출 항목 입력
- `/diagnose/precision/`: 기본 정보·9대 비용 입력
- `/result/simple/`: 선택한 두 비용의 큰 비교 카드
- `/result/precision/`: KPI·레이더·비용 표·What-if

입력값은 React 메모리에만 저장합니다. localStorage, 쿠키, 서버 DB, 저장 API, 외부 분석 도구를 사용하지 않습니다. 새로고침·직접 결과 링크 방문 시 재입력을 안내합니다. 예시는 실제 집계 데이터에서 생성하고 화면에 예시임을 표시합니다.

## Gap과 시뮬레이션

Gap = 내 비용−중앙값. 중앙값이 양수이면 백분율과 레이더 지수를 계산합니다. 중앙값 0은 비교 어려움으로 표시하고 레이더 축도 빈 값으로 처리합니다. 지수는 차트에서만 최대 200으로 제한하며 표는 원래 값을 보존합니다. ±15%는 임시 표시 기준으로 적정 투입량을 뜻하지 않습니다.

9대 비용 기준 추정 잔여액 = 매출−9대 비용 합계. 공식 순수익으로 표시하지 않습니다. What-if 변경률은 −30%~+30%, 1% 간격이며 `비용×(1+변경률/100)`을 적용합니다. 현재 매출이 유지된다는 가정 아래 비용만 바꾸는 시나리오입니다. 생산량·품질 변화, 투자 회수, 실제 미래 수익을 예측하지 않습니다. 기회비용·감가상각비 감소는 현금 절감과 다릅니다.

지원 브라우저에는 `set_cost_scenario` WebMCP 도구를 기능 감지 후 등록합니다. 표시된 슬라이더와 같은 상태를 조정하며, 잘못된 카테고리·범위는 거부합니다. 지원하지 않거나 등록 실패한 브라우저에서도 일반 UI가 작동합니다. 브라우저 보안 정책으로 이 환경의 직접 UI/WebMCP 실행 검증은 완료하지 못했습니다.

## 한계

제공 표본 내 비교이며 전국 농가 전체의 상위 10%를 추정하지 않습니다. 가온 여부·재배조건·기간 차이를 완전히 통제하지 않습니다. 결측의 의미, 중복 식별값, 조사 기간 정의를 제공자에게 확인한 뒤 품질 정책을 갱신해야 합니다. 작은 상위군 중앙값은 불안정할 수 있습니다. 비용 차이는 과다·부족의 인과적 증거가 아니며 점검을 위한 참고값입니다. 로그인·회원가입·DB·AI 상담·PDF·지도·장기 추세는 구현하지 않았습니다.
