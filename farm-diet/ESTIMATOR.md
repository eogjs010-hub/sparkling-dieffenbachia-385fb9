# 유지보수·감가상각비 보조 계산

농진청 「2026 농산물 소득조사 분석방법」을 시각적으로 확인한 기준입니다. 기준표는 `src/data/asset-standards.json`에 버전·연도·원문 링크·쪽수를 기록했습니다.

- 원문: https://www.nongsaro.go.kr/portal/ps/pst/pstb/pstbc/mngmtDtaDtl.ps?nttSn=846&menuId=PS03213
- 감가상각: 인쇄 47·51쪽, 수리유지비: 52쪽, 자산 수명: 80~84쪽. PDF 파일의 실제 페이지는 인쇄 쪽수 +5입니다.
- 원문 PDF SHA-256: 9ac804b3b57cdf2227c521f669a8ac7aa8970632fd4f8430bec44ee347a1893e

## 구현 기준

신조 설치·구입 금액 / 내용연수 × 해당 작목 사용 비중으로 연간 평가비용을 구합니다. 보조금·설치 부대비용을 포함한 금액이며, 이 계산식에는 잔존가액을 별도 차감하지 않습니다. 파이프 골조 10년, 원예시설 온풍기 7년, 온수보일러 10년, 양수기 8년, 농업용 트랙터 12년, 온실 철골 20년, 수평커튼 개폐장치 10년을 확인했습니다. 커튼 구동장치의 수명을 커튼 원단에 적용하지 않습니다.

47쪽 지침은 내용연수 초과 자산을 계속 사용할 때 현재 사용연수를 분모로 적용할 수 있다고 설명합니다. 따라서 10년 기준 하우스를 12년 계속 사용하는 경우 자동 0원으로 계산하지 않습니다. 예: 3,000만원 / 12년 = 250만원/년. 1년 전체 사용을 가정합니다. 중고 구입, 연중 처분, 자본적 지출, 세무상 상각은 간편 계산 대상에서 제외합니다.

수리비는 실제 해당 작목 연간 지출을 입력하거나 조사 참고값 사용을 명시적으로 선택합니다. 신조가의 3~5% 같은 임의 비율은 사용하지 않습니다. 대규모 교체·개량비는 별도 확인하도록 안내합니다.

수리비 참고값은 원본의 `수리유지비_합계`를 기존 유효 행(회계 검증 포함)에서 작목·지역별로 집계한 전체 표본 중앙값입니다. `cohortMedianRepairCost`로 저장합니다. 기간 비교는 연도별 중앙값의 동일 비중 평균이며, 기존 지역 표본 기준을 충족하지 못하면 기간 전체를 전국으로 fallback합니다. 기존 9대 비용·상위 10% 벤치마크 값은 변경하지 않았습니다. 원본 300평 참고 수리비는 사용자 면적에 확대하고, 최종 진단에서 합계를 300평으로 한 번만 환산합니다.

시설별 감가상각 합 + 수리비 합을 원 단위로 최종 반올림합니다. 적용은 기존 항목에 추가하지 않고 교체합니다. 모든 해당 시설·기계 포함 여부를 확인받으며 같은 구입비를 중복 입력하지 않도록 안내합니다. 계산 내역은 메모리 세션에만 보존하고 결과·인쇄물에 표시합니다. 직접 수정하면 추산 표시를 해제하고, 작목·면적·지역·비교기간 변경 시 추산값을 초기화합니다.

## 아직 확보하지 않은 기본값

지역·작목별 표준 설치비, 다겹보온커튼 원단 수명, 표준 수리비율은 검증된 기본값이 없습니다. 1,500만원 등 예시를 농진청 평균으로 표시하지 않습니다. 금액을 모르면 견적·장부 확인 또는 비교 제외로 안내합니다. 노동 단계별 임금·투입시간, 비료·농약 처방량, 물가지수·실시간 단가 API는 이번 계산기에 적용하지 않습니다. 처방·가격 데이터의 조건과 연도·단위가 확보된 뒤 별도 설계가 필요합니다.
